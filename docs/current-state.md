## 현재 구현된 핵심 흐름

### 학생

- 대문에서 4자리 수업 코드 입력 또는 학급 QR로 입장
- QR로 이미 학급이 정해진 경우 프로필 화면에서 수업 코드를 다시 입력하지 않음
- 수업 코드와 QR 모두 서버의 같은 학급 상태 확인을 거쳐 동일한 입장 흐름 사용
- 학생이 없는 새 학급은 신규 프로필 생성 화면을 바로 열고, 학생이 있는 학급은 `새로 시작하기`와 `내 그림 이어가기`를 표시
- 동물·별명·그림 비밀번호 3개로 익명 프로필 생성 및 어느 태블릿에서나 기존 익명 학생 ID 재입장
- 공유 태블릿 학생 전환 시 기존 활성 세션을 해지하고, 최근 학생 목록은 입장 화면에 표시하지 않음
- 기초 → 따라 그리기 → 관찰 그리기 → 자유 창작의 4단계 활동
- 터치·스타일러스 캔버스, 자동 저장, 오프라인 임시 보존, 작품 보관함
- 점선·시범 가이드는 작품 원본과 분리
- 소감과 짧은 글을 작품에 연결

### 교사

- 교사 로그인, 학급 생성, QR·수업 코드 관리
- 로컬 개발 서버의 `/teacher`는 최근 사용한 로컬 교사로 자동 로그인하며, production과 Sites는 기존 ChatGPT 인증을 그대로 요구
- 오늘 활동 선택, 전체·개별 텍스트 메시지
- 학생 진행 상태·썸네일·과거 작품 확인
- 학생 카드에서 동물·별명·프로필 생성 시각·마지막 접속 시각·전체/진행/완료 작품 수·중복 별명 여부를 읽기 전용으로 확인
- 개인 QR 재발급은 기본 교사 UI에서 제거했으며, 가족 제한 공유 기반 기능은 기존 범위를 유지

### 저장·권한

- 관계형 기록은 D1, 이미지·썸네일은 R2에 저장
- AI 호출은 서버에서만 수행

- 학생증과 동물 선택 버튼은 정사각 셀로 재구성한 `public/brand/animal-portraits-v2.png`의 동물 초상 10개를 사용한다. 기본 이모지를 억지로 키우거나 동물을 가로로 늘리지 않고, 선택한 동물의 큰 초상을 참고 화면과 같은 중심과 비율로 표시한다.
- 학생증의 동물 초상은 실제 불투명 영역을 파란 원의 중심에 맞추고, 별명은 배경 그림의 점선 상자 전체에서 가로·세로 중앙 정렬한다. 배경에 이미 그려진 비밀번호 상자를 다시 HTML 테두리로 덮지 않고 `그림 비밀번호` 리본 문구와 선택한 그림·물음표만 올린다.
- 리본 문구는 파란 리본의 가운데 띠 중심에 맞추고, 비밀번호 그림과 물음표에는 별도의 상하 이동 보정을 적용하지 않아 각 점선 칸의 기하학적 중앙에 놓는다.
- 넓은 화면의 `다시 골라요`와 `한 칸 지우기`는 절대 좌표를 사용하지 않고 3번 비밀번호 단계의 설명 행에 포함한다. 2번·3번 시작선에는 구분선을 표시해 각 단계와 보조 버튼의 소속을 명확하게 구분한다.
- 2026-08-18 실제 브라우저 좌표 검증에서 `1488×1057`, `1213×815`, `1024×768`, `768×1024`, `844×390`, `390×844`, `320×568` 모두 보조 버튼과 그림 선택 칸·입장 버튼의 교차가 0건이었고 가로 오버플로도 없었다. 세 비밀번호 아이콘과 각 점선 칸의 중심 좌표 차이도 모든 화면에서 0px로 확인했다.
