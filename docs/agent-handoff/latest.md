## 수정한 문제

제품주가 실사용에서 보고한 3건.

1. **따라 그리기 고양이가 몸 없이 완성됨** — curious-cat 레슨이 얼굴→귀→눈→수염에서 바로 꼬리로 건너뛰었다. "얼굴 아래로 몸과 다리를 이어요" 단계를 5단계로 추가하고 몸 타원 가이드, 몸에 붙는 꼬리 가이드로 수정했다(6→7단계). 2단계 나머지 9개 레슨은 몸 단계가 이미 있음을 전수 확인.
2. **선생님 메시지가 안 사라지고 버튼을 가림** — 고정 오버레이 배너(z-index 7)에 닫기 수단이 없어, 메시지가 있는 동안 밑에 깔린 따라 그리기 선택지·버튼이 눌리지 않았다("버튼이 안 눌러져"의 원인). 닫기 버튼(44px)을 추가하고 닫은 메시지 id를 sessionStorage(`wiggle:dismissed-teacher-message`)에 기억 — 같은 메시지는 다시 뜨지 않고 새 메시지는 다시 보인다.
3. **연필·크레용·마커·수채붓 구분이 안 됨** — 필압 없는 입력(마우스·손가락)에서 마커가 연필과 거의 동일했다. 마커 1.6배 폭 불투명, 수채붓 2배 폭 + 옅은 번짐 패스(알파 0.12 외곽)로 질감을 벌렸다. **연필(pencil)·크레용·기존 pen 렌더 값은 불변** — 기존 저장 작품 렌더 보존. 마커·수채붓은 미배포 도구라 조정이 안전하다.

## 남은 위험

- 메시지 배너를 닫아도 새 메시지마다 다시 뜬다 — 교사가 연속 발송하면 그때마다 닫아야 한다(의도된 동작이나 관찰 필요).
- 수채붓 번짐 패스는 획당 stroke 2회 — 저사양 기기 장획에서 미미한 비용 증가.
- 진행 중이던 고양이 레슨 작품은 currentStep이 옛 단계 번호 기준이라 단계 문구가 한 칸 밀려 보일 수 있다(새로 시작하면 정상). 배포 시점에 진행 중 작품이 있으면 안내 필요.
